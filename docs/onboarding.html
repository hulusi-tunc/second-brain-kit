Your second brain, from zero to the first morning brief

You write things down the way they come. Claude files them into a wiki about your work, keeps a list of who owes what to whom, and tells you each morning the one thing that matters. It is all plain markdown in a private git repo you own.

set it up

The first hour, seven steps

Tick each one when it is done. Your progress stays in this browser.

0 of 7

  1. Make your private copy

    5 min

    First make an empty private repo on GitHub for your notes (no README, no license). Then clone the kit and point it there. Clone it, don't use "Use this template": a clone keeps the kit's history, so later updates merge by themselves.

    git clone https://github.com/hulusi-tunc/second-brain-kit.git ~/second-brain
cd ~/second-brain
git remote rename origin kit
git remote add origin git@github.com:you/your-brain.git
git push -u origin main

    Your notes go to origin, your private repo. The kit stays a second remote called kit. Nothing you write ever goes back to it.

  2. Run the setup

    5 min
    ./setup.sh

    It asks a few short questions and you can press Enter on any of them:

    • your name, what you do in one line, the topics you think about
    • the languages you write in, how the brain should write, what it should never do
    • where your code projects live and a folder you drop documents into
    • which scheduled jobs to turn on. Say yes to translate and brief for now, add the rest later with ./setup.sh jobs
    • whether to install the Mac app. Say no for now, it is a 575 MB download. Come back to it after the first week.

    If it prints export PATH="$HOME/.local/bin:$PATH", add that line to your ~/.zshrc and open a new terminal, so brain works everywhere.

  3. Capture your first three things

    2 min

    From any terminal, in any folder. Write the way you would say it, no formatting. Use real things from this week: a promise, a decision, something you keep forgetting.

    brain "Sam said the quote is fine if we ship by the 20th"
brain "decided: no new clients until Northwind is live"
brain "I keep forgetting to send Maya the invoice"
brain ls

    Each one lands in raw/<today>.md under its time. brain ls shows what is waiting. Nothing has been processed yet. That is the next step's job.

  4. Let it get to know you

    15 min
    cd ~/second-brain
claude
# then, inside Claude Code:
/interview

    Claude asks one question at a time and writes your answers into wiki/about-me.md, wiki/voice.md and new pages for the people and projects you mention. Answer like you are talking to a new colleague. Stop whenever you want. What it didn't get to goes into wiki/open-questions.md for next time.

    This is what turns it from a notes folder into something that knows you. Fifteen minutes now saves a month of the brain guessing.

  5. Process the inbox

    3 min
    /translate

    Your three notes from step 3 get merged into the wiki. The promises go into commitments.md with an id like c3f9a21b, and the raw file moves to archive/ unchanged. Open commitments.md and look: "you owe Sam: ship by the 20th" and "you owe Maya: the invoice" should both be there.

    From tonight the nightly job runs this at 23:55. You only run it by hand when you want the answer now.

  6. Ask it something

    5 min

    Still in Claude Code, in the brain folder. Plain questions work:

    what do I owe this week?
what did I decide about new clients?
/prep Sam

    /prep Sam is the one to use before a call: what you talked about last time, who owes what, three questions to ask. Then close a promise from any terminal:

    brain done c3f9a21b

  7. Tomorrow at 08:30

    0 min

    The brief job writes data/brief.md and shows one notification: the one thing for today. If nothing arrives, check the jobs:

    brain health

    That's the whole setup. The habit from here is just brain "..." whenever something comes up, and /log at the end of a long Claude Code session, so the brain keeps what that session taught it about you.

trust

Four rules that keep it trustworthy

They are in CLAUDE.md and every loop follows them. Change anything else in the kit, but keep these.

  1. Nothing is deleted from raw/ or archive/. The original of everything you said is always there.
  2. The wiki is merged, never overwritten. Claude reads a page before it changes it.
  3. When it isn't sure, it says so in the entry ("unsure: ...") instead of guessing.
  4. private/ stays private. It never enters git, and nothing from it is copied into other files.
week two

When the basics feel normal

Brain Home

A dashboard of everyone and everything in your wiki, closer to the middle when it needs you. Mark things done or drop them there. brain home

Slack

One read-only connection per workspace, so the brief and /prep see your chats. It can't post. brain slack add work

Fortune teller

Reads Slack for what is heading your way: two people promising a client different dates, your project discussed without you. brain fortune

The Mac app

Lives in the notch. Hold a key to dictate anywhere, ask the brain out loud, get notes after every call. Everything is transcribed on your Mac. See app/README.md.

Your phone

Open the same private repo in Claude Code in the Claude app. The jobs push, so your phone sees today's brain.

Kit updates

When the kit ships something new, pull it in. Your notes and the kit's code live in different folders, so it merges cleanly. git pull kit main

when something is off

Fixes for the usual problems

No brief in the morningbrain health shows each job's last good run and why it failed.
"paused" notificationYou hit your Claude usage limit. The jobs wait for the reset by themselves. brain resume clears the pause early.
"logged out" notificationThe jobs' Claude login is gone. Run brain login.
Notes piling up in raw/brain ls, then /translate in Claude Code.
